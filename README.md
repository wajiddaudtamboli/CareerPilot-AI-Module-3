# CareerPilot AI - Resume & Cover Letter Generator# CareerPilot AI - ATS-Friendly Resume & CV Generator



🚀 An AI-powered web application that helps users generate professional resumes and cover letters with ATS (Applicant Tracking System) scoring analysis.🚀 An AI-powered web application that helps users generate professional resumes and cover letters, check their ATS (Applicant Tracking System) score, and download documents in PDF format — all in a clean, responsive design.
